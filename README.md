# MoiréSkin Simulation Public Demo

Read-only Streamlit proof of concept for rigid-object contact simulation and
local 2.5D reconstruction from Moiré deformation plus see-through appearance.

The hosted app exposes simulation controls only. It does not generate datasets,
train models, or accept filesystem paths.

```bash
python -m pip install -r requirements.txt
streamlit run moire_public_app.py
```

This is a synthetic research prototype, not a validated real-sensor accuracy
claim.
